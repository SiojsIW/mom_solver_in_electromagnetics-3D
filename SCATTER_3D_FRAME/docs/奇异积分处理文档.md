## 1. 背景：EFIE 矩量法公式

对于理想电导体（PEC）的电磁散射问题，电场积分方程（EFIE）经伽辽金测试后，阻抗矩阵元素为：

$$Z_{mn} = j\omega\mu \underbrace{\iint \mathbf{f}_m(\mathbf{r}) \cdot \mathbf{f}_n(\mathbf{r}') G(\mathbf{r},\mathbf{r}') dS' dS}_{P\text{ 项（矢量势）}} + \frac{1}{j\omega\varepsilon} \underbrace{\iint (\nabla \cdot \mathbf{f}_m(\mathbf{r})) (\nabla' \cdot \mathbf{f}_n(\mathbf{r}')) G(\mathbf{r},\mathbf{r}') dS' dS}_{Q\text{ 项（标量势）}}$$

其中自由空间三维格林函数：

$$G(\mathbf{r},\mathbf{r}') = \frac{e^{-jkR}}{4\pi R}, \quad R = |\mathbf{r} - \mathbf{r}'|, \quad k = \frac{2\pi}{\lambda}$$

用波数 $k$ 和自由空间波阻抗 $\eta_0 = 120\pi\ \Omega$ 表示：

$$j\omega\mu = jk\eta_0, \quad \frac{1}{j\omega\varepsilon} = -\frac{j\eta_0}{k}$$

RWG 基函数在三角形 $T$ 上为：

$$\mathbf{f}(\mathbf{r}) = C \cdot (\mathbf{r} - \mathbf{r}_{\text{opp}}), \quad C = \pm \frac{L}{2A}$$

其中正三角形取 $C = L/2A$，负三角形取 $C = -L/2A$，$\mathbf{r}_{\text{opp}}$ 为公共边对顶点。散度 $\nabla \cdot \mathbf{f} = 2C$ 为常数。

---

## 2. 奇异性来源与提取策略

当源三角形和场三角形**相同**或**共用一条边**时，$G(\mathbf{r},\mathbf{r}') \propto 1/R$ 在 $\mathbf{r} \to \mathbf{r}'$ 时奇异。处理策略为**奇异性提取**：

$$G(\mathbf{r},\mathbf{r}') = \underbrace{\frac{1}{4\pi R}}_{G_{\text{sing}}(\text{解析处理})} + \underbrace{\frac{e^{-jkR} - 1}{4\pi R}}_{G_{\text{smooth}}(\text{数值积分})}$$

| 情况 | 处理方法 | 高斯阶数 | 对应函数 |
|------|---------|---------|---------|
| 同一三角形（自作用） | 解析 1/R 边界积分 + G_smooth 12点数值积分 | 12 点 | `CALC_EFIE_SELF_TRI_PAIR` |
| 共用一边（相邻） | 完整格林函数 12 点双重高斯（弱奇异可积） | 12 点 | `CALC_EFIE_MATRIX_ELEMENT` 相邻分支 |
| 其他（非奇异） | 完整格林函数数值积分 | 调用者指定 | `CALC_EFIE_MATRIX_ELEMENT` 远区分支 |

---

## 3. 格林函数的光滑提取

光滑格林函数定义为：

$$G_{\text{smooth}}(\mathbf{r},\mathbf{r}') = \frac{e^{-jkR} - 1}{4\pi R}$$

**关键性质：**

- 在 $R \to 0$ 处有限且光滑：

$$G_{\text{smooth}}(0) = \lim_{R \to 0} \frac{e^{-jkR} - 1}{4\pi R} = -\frac{jk}{4\pi}$$

- 与完整格林函数的关系：

$$G(\mathbf{r},\mathbf{r}') = G_{\text{smooth}}(\mathbf{r},\mathbf{r}') + \frac{1}{4\pi R}$$

> **注意**：完整格林函数 $G(0) = \infty$，代码中对 $R < 10^{-10}$ 的情况返回 $(0,0)$ 并跳过。这虽然避免了除零，但同时丢弃了光滑虚部 $-jk/(4\pi)$ 的对角线贡献。因此自作用项必须采用奇异提取法，而不是直接数值积分。

## 4. 边界积分法：解析 1/R 势

对平面三角形 $T$（顶点 $\mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3$，单位法向量 $\hat{\mathbf{n}}$），用边界积分将面积分转化为围线积分。

### 4.1 标量势 $\int_T 1/R\ dS'$

完整的 Wilton 边界积分公式（含立体角修正）：

$$I_0(\mathbf{r}) = \int_T \frac{1}{|\mathbf{r} - \mathbf{r}'|} dS' = -\sum_{i=1}^{3} h_i \cdot \ln\left(\frac{R_i^+ + s_i^+}{R_i^- + s_i^-}\right) - |d| \cdot \Omega$$

其中 $d = (\mathbf{r} - \mathbf{v}_1) \cdot \hat{\mathbf{n}}$ 为场点到平面的有符号距离，$\Omega$ 为三角形对场点张的立体角（详见下文）。当面内点 $d=0$ 时立体角项自动归零，退化为纯边界积分形式。

其中对第 $i$ 条边（起点 $\mathbf{v}_i^-$，终点 $\mathbf{v}_i^+$）：

| 符号 | 定义 | 含义 |
|------|------|------|
| $\hat{\mathbf{t}}_i$ | $(\mathbf{v}_i^+ - \mathbf{v}_i^-) / L_i$ | 边单位切向量 |
| $\hat{\mathbf{m}}_i$ | $\hat{\mathbf{n}} \times \hat{\mathbf{t}}_i$ | 边内法向（指向三角形内部） |
| $h_i$ | $(\mathbf{r} - \mathbf{v}_i^-) \cdot \hat{\mathbf{m}}_i$ | 场点到边所在直线的**有符号**垂直距离 |
| $s_i^-$ | $(\mathbf{r} - \mathbf{v}_i^-) \cdot \hat{\mathbf{t}}_i$ | 场点在边起点方向的有符号投影 |
| $s_i^+$ | $(\mathbf{r} - \mathbf{v}_i^+) \cdot \hat{\mathbf{t}}_i$ | 场点在边终点方向的有符号投影 |
| $R_i^-$ | $\|\mathbf{r} - \mathbf{v}_i^-\|$ | 场点到边起点的 3D 距离 |
| $R_i^+$ | $\|\mathbf{r} - \mathbf{v}_i^+\|$ | 场点到边终点的 3D 距离 |

**符号约定**：公式前的**负号**确保当 $\mathbf{r}$ 在三角形内部时 $I_0(\mathbf{r}) > 0$。

立体角 $\Omega$ 由 Van Oosterom & Strackee 公式计算：

$$\Omega = 2 \arctan\left(\frac{|\mathbf{r}_1 \cdot (\mathbf{r}_2 \times \mathbf{r}_3)|}{r_1 r_2 r_3 + r_1(\mathbf{r}_2 \cdot \mathbf{r}_3) + r_2(\mathbf{r}_3 \cdot \mathbf{r}_1) + r_3(\mathbf{r}_1 \cdot \mathbf{r}_2)}\right)$$

其中 $\mathbf{r}_i = \mathbf{v}_i - \mathbf{r}$，$r_i = |\mathbf{r}_i|$。当面内点 $d=0$ 时此项自动归零，公式退化为面内版本。

### 4.2 线性势 / 矢量势

线性势指三个重心坐标系数：

$$c_i(\mathbf{r}) = \int_T \frac{\lambda_i(\mathbf{r}')}{|\mathbf{r}-\mathbf{r}'|} dS', \quad i=1,2,3$$

其中 $\lambda_i$ 是相对于顶点 $\mathbf{v}_i$ 的重心坐标。它们满足基本恒等式：

$$c_1 + c_2 + c_3 = I_0(\mathbf{r})$$

代码中不直接计算 $c_i$ 的每条边分配公式，而是先计算**矢量势**：

$$\mathbf{I}_{\text{vec}}(\mathbf{r}) = \int_T \frac{\mathbf{r}'}{R} dS' = \mathbf{p} \, I_0 + \mathbf{I}_{\text{shifted}}$$

其中 $\mathbf{p} = \mathbf{r} - h\hat{\mathbf{n}}$ 是场点在三角形平面上的投影，$h = (\mathbf{r}-\mathbf{v}_1)\cdot\hat{\mathbf{n}}$。

平移矢量势通过边界积分得到：

$$\mathbf{I}_{\text{shifted}} = \int_T \frac{\mathbf{r}' - \mathbf{p}}{R} dS' = \frac12 \sum_{e=1}^{3} \hat{\mathbf{m}}_e^{\text{out}} \left[ \rho_e^2 \ln\left(\frac{R_{\text{start}} + s_{\text{start}}}{R_{\text{end}} + s_{\text{end}}}\right) + s_{\text{start}} R_{\text{start}} - s_{\text{end}} R_{\text{end}} \right]$$

其中：
- $\hat{\mathbf{m}}_e^{\text{out}} = -\hat{\mathbf{m}}_e$ 为边的外法向（指向三角形外部）
- $\rho_e^2 = h^2 + d_e^2$，$d_e = (\mathbf{p} - \mathbf{v}_{\text{start}}) \cdot \hat{\mathbf{m}}_e^{\text{out}}$ 为投影点到边的平面内距离
- $s_{\text{start}}, s_{\text{end}}$ 为投影点沿边切向到起/终点的有符号投影
- $R_{\text{start}}, R_{\text{end}}$ 为场点到边起/终点的 3D 距离

得到矢量势后，利用 $\mathbf{I}_{\text{vec}} = c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + c_3 \mathbf{v}_3$ 和 $c_1+c_2+c_3 = I_0$ 解出三个线性势：

$$c_1 = \frac{[(\mathbf{I}_{\text{vec}} - \mathbf{v}_3 I_0) \times (\mathbf{v}_2 - \mathbf{v}_3)] \cdot \hat{\mathbf{n}}}{2A}$$

$$c_2 = \frac{[(\mathbf{v}_1 - \mathbf{v}_3) \times (\mathbf{I}_{\text{vec}} - \mathbf{v}_3 I_0)] \cdot \hat{\mathbf{n}}}{2A}$$

$$c_3 = I_0 - c_1 - c_2$$

> **为什么不用直接分配公式？** 旧实现采用每条边向两个端点分配贡献的公式，但该公式不满足 $c_1+c_2+c_3 = I_0$，导致自作用 P 项系统性错误。矢量势边界积分法自动满足该恒等式，且经过 `test_singular.F90` 验证与直接法一致。

### 4.3 近奇异性处理

当场点 $\mathbf{r}$ 非常靠近三角形某顶点时，$R_i^\pm + s_i^\pm \to 0$ 导致对数计算不稳定。利用恒等式 $R^2 - s^2 = \rho^2$，改写 $R + s = \rho^2 / (R - s)$。

#### 标量势（`ANALYTIC_SCALAR_POT_1_OVER_R`）

标量势中 $\rho^2 = h^2 + H_I^2$（面外距离平方 + 面内垂直距离平方，与线性势一致），且额外处理 $|H_I| < 10^{-12}$（场点在边的延长线上）使贡献为0。

**恒等式**：$R + S = \rho^2 / (R - S)$，$\ln(R+S) = \ln(\rho^2) - \ln(R-S)$

**靠近起点** ($R_{\text{start}} + s_{\text{start}} \to 0$)：
$$H_I \cdot \ln\left(\frac{R_{\text{end}} + s_{\text{end}}}{R_{\text{start}} + s_{\text{start}}}\right) \approx H_I \cdot \big[\ln(R_{\text{end}} + s_{\text{end}}) + \ln(R_{\text{start}} - s_{\text{start}}) - \ln(h^2 + H_I^2)\big]$$

**靠近终点** ($R_{\text{end}} + s_{\text{end}} \to 0$)：
$$H_I \cdot \ln\left(\frac{R_{\text{end}} + s_{\text{end}}}{R_{\text{start}} + s_{\text{start}}}\right) \approx H_I \cdot \big[\ln(h^2 + H_I^2) - \ln(R_{\text{end}} - s_{\text{end}}) - \ln(R_{\text{start}} + s_{\text{start}})\big]$$

#### 线性势/矢量势（`ANALYTIC_LINEAR_POT_1_OVER_R`）

线性势中 $\rho^2 = h^2 + d_i^2$（面外距离平方 + 面内投影点到边距离平方），且代码中对 $\rho^2$ 和 $R-s$ 加了 `MAX(..., EPS)` 保护。

**靠近起点** ($R_{\text{start}} + s_{\text{start}} \to 0$)：
$$\ln\left(\frac{R_{\text{start}} + s_{\text{start}}}{R_{\text{end}} + s_{\text{end}}}\right) \approx \ln(\rho^2) - \ln(R_{\text{start}} - s_{\text{start}}) - \ln(R_{\text{end}} + s_{\text{end}})$$

**靠近终点** ($R_{\text{end}} + s_{\text{end}} \to 0$)：
$$\ln\left(\frac{R_{\text{start}} + s_{\text{start}}}{R_{\text{end}} + s_{\text{end}}}\right) \approx \ln(R_{\text{start}} + s_{\text{start}}) + \ln(R_{\text{end}} - s_{\text{end}}) - \ln(\rho^2)$$

## 5. 自作用项计算

当源三角形和场三角形是**同一个三角形** $T$ 时，使用 `CALC_EFIE_SELF_TRI_PAIR(MESH, TRI_ID, RWG_M, RWG_N, K, ETA0, Z_PAIR)` 计算两个 RWG 基函数在该三角形上的作用。

函数内部根据 `TRI_ID` 分别提取 `RWG_M` 和 `RWG_N` 的系数 $C_M, C_N$ 和对顶点 $\mathbf{r}_{\text{opp}}^M, \mathbf{r}_{\text{opp}}^N$。

### 5.1 Q 算子（标量势部分）

$$Q = \iint_{T \times T} (\nabla \cdot \mathbf{f}_M)(\nabla' \cdot \mathbf{f}_N) \cdot G(\mathbf{r},\mathbf{r}') dS' dS = 4 C_M C_N \iint_{T \times T} G(\mathbf{r},\mathbf{r}') dS' dS$$

**解析 1/R 部分**：

$$Q_{\text{sing}} = -\frac{C_M C_N}{\pi} J_0$$

其中 $J_0 = \iint_{T \times T} 1/R\, dS' dS$ 通过双层积分计算：

$$J_0 = \int_T I_0(\mathbf{r}) dS \approx A_T \sum_{i=1}^{12} w_i \cdot I_0(\mathbf{r}_i)$$

**G_smooth 数值部分**：

$$Q_{\text{smooth}} = -4 C_M C_N \iint_{T \times T} G_{\text{smooth}}(\mathbf{r},\mathbf{r}') dS' dS = -4 C_M C_N \, I_1^G$$

### 5.2 P 算子（矢量势部分）

$$P = \iint_{T \times T} \mathbf{f}_M(\mathbf{r}) \cdot \mathbf{f}_N(\mathbf{r}') G(\mathbf{r},\mathbf{r}') dS' dS$$

展开 $\mathbf{f}_M \cdot \mathbf{f}_N = C_M C_N (\mathbf{r} - \mathbf{r}_{\text{opp}}^M) \cdot (\mathbf{r}' - \mathbf{r}_{\text{opp}}^N)$：

$$P = C_M C_N \iint_{T \times T} \left[ \mathbf{r} \cdot \mathbf{r}' - \mathbf{r}_{\text{opp}}^N \cdot \mathbf{r} - \mathbf{r}_{\text{opp}}^M \cdot \mathbf{r}' + \mathbf{r}_{\text{opp}}^M \cdot \mathbf{r}_{\text{opp}}^N \right] G(\mathbf{r},\mathbf{r}') dS' dS$$

**解析 1/R 部分**：

$$P_{\text{sing}} = \frac{C_M C_N}{4\pi} \Big[ J_{\text{rdot}} - \mathbf{r}_{\text{opp}}^N \cdot \mathbf{J}_{\text{rio}} - \mathbf{r}_{\text{opp}}^M \cdot \mathbf{J}_{\text{vec}} + (\mathbf{r}_{\text{opp}}^M \cdot \mathbf{r}_{\text{opp}}^N) J_0 \Big]$$

其中：

| 符号 | 计算方式 |
|------|---------|
| $J_0 = \int_T I_0(\mathbf{r}) dS$ | 标量势 × 外层 12 点高斯积分 × $A_T$ |
| $\mathbf{J}_{\text{rio}} = \int_T \mathbf{r} \, I_0(\mathbf{r}) dS$ | 场坐标 × 标量势 × 外层高斯积分 × $A_T$ |
| $\mathbf{J}_{\text{vec}} = \int_T \mathbf{I}_{\text{vec}}(\mathbf{r}) dS$ | 矢量势 × 外层高斯积分 × $A_T$ |
| $J_{\text{rdot}} = \int_T \mathbf{r} \cdot \mathbf{I}_{\text{vec}}(\mathbf{r}) dS$ | $\mathbf{r} \cdot \mathbf{I}_{\text{vec}}$ × 外层高斯积分 × $A_T$ |

> **M 与 N 的对应关系**：代码中 `M` 代表源 RWG，`N` 代表场 RWG。因此 $\mathbf{J}_{\text{vec}}$（源坐标加权）与 $\mathbf{r}_{\text{opp}}^M$（源对顶点）配对，$\mathbf{J}_{\text{rio}}$（场坐标加权）与 $\mathbf{r}_{\text{opp}}^N$（场对顶点）配对。

**G_smooth 数值部分**：

$$P_{\text{smooth}} = C_M C_N \Big[ (\mathbf{r}_{\text{opp}}^M \cdot \mathbf{r}_{\text{opp}}^N) I_1^G - \mathbf{r}_{\text{opp}}^N \cdot \mathbf{I}_3^G - \mathbf{r}_{\text{opp}}^M \cdot \mathbf{I}_2^G + I_4^G \Big]$$

其中四个格林积分由 `CALC_GREEN_SMOOTH_INTEGALS` 计算。

### 5.3 完整自阻抗

$$Z_{\text{self}} = jk\eta_0 \cdot (P_{\text{sing}} + P_{\text{smooth}}) + \frac{j\eta_0}{k} \cdot (Q_{\text{sing}} + Q_{\text{smooth}})$$

计算流程：

```
1. INIT_GAUSS_TRI(12点) → 初始化高斯数据
2. 获取全部12个高斯点的全局坐标 GLOBAL_PTS(3,12)
3. 对每个高斯点 r_i:
   a. ANALYTIC_SCALAR_POT_1_OVER_R(r_i) → I0(r_i)
   b. ANALYTIC_LINEAR_POT_1_OVER_R(r_i) → c1,c2,c3
   c. IVEC = c1*V1 + c2*V2 + c3*V3
   d. 累加 SUM_I0, SUM_R_I0, SUM_IVEC, SUM_R_DOT_IVEC
4. J0 = SUM_I0 × AREA, 同理得 J_RI0, J_VEC, J_RDOT
5. Q_sing = -C_M*C_N·J0/π
6. P_sing = C_M*C_N/(4π) × [J_RDOT - r_opp^N·J_RI0 - r_opp^M·J_VEC + (r_opp^M·r_opp^N)·J0]
7. CALC_GREEN_SMOOTH_INTEGALS(T, T, 12pt) → I1,I2,I3,I4
8. P_smooth = C_M*C_N × [(r_opp^M·r_opp^N)·I1 - r_opp^N·I3 - r_opp^M·I2 + I4]
9. Q_smooth = -4·C_M*C_N·I1
10. Z_self = jkη0·(P_sing+P_smooth) + jη0/k·(Q_sing+Q_smooth)
```

## 6. 相邻三角形（弱奇异性）

当两个三角形共享一条边时，积分核在公共边处有 $1/R$ 弱奇异性（在二维二重积分中可积）。

**处理方式**：在 `CALC_EFIE_MATRIX_ELEMENT` 中识别相邻关系（共用两个顶点），对该三角形对使用 12 点高斯双重积分 + 完整格林函数计算，不再调用单独的相邻项子程序。

相邻分支的 P/Q 公式与非奇异情况相同，仅高斯阶数固定为 12 点。

---

## 7. 非奇异情况

对于既不相同也不相邻的三角形对，直接使用双重高斯积分 + 完整格林函数：

$$Z_{mn} = \sum_{i,j=1}^{2} C_M^i C_N^j \left[ jk\eta_0 \cdot P_{ij} + \frac{j\eta_0}{k} \cdot Q_{ij} \right]$$

其中 $P_{ij}$ 和 $Q_{ij}$ 由 `CALC_GREEN_INTEGALS` 计算：

$$I_1 = \iint G\ dS' dS, \quad \mathbf{I}_2 = \iint \mathbf{r}_{\text{obs}} G\ dS' dS$$
$$\mathbf{I}_3 = \iint \mathbf{r}_{\text{src}} G\ dS' dS, \quad I_4 = \iint (\mathbf{r}_{\text{src}} \cdot \mathbf{r}_{\text{obs}}) G\ dS' dS$$

$$P = (\mathbf{r}_{\text{opp}}^M \cdot \mathbf{r}_{\text{opp}}^N) I_1 - \mathbf{r}_{\text{opp}}^N \cdot \mathbf{I}_3 - \mathbf{r}_{\text{opp}}^M \cdot \mathbf{I}_2 + I_4$$

$$Q = -4 I_1$$

> **注意 I₂/I₃ 的对应关系**：`I2` 存场（观测）三角形坐标加权，`I3` 存源三角形坐标加权。`M` 为源 RWG，`N` 为场 RWG，因此 $-\mathbf{r}_{\text{opp}}^N$（场对顶点）点乘源坐标 $\mathbf{r}$ 对应 `I3`，$-\mathbf{r}_{\text{opp}}^M$（源对顶点）点乘场坐标 $\mathbf{r}'$ 对应 `I2`。

## 8. 数值积分方案

使用 Dunavant 三角形对称高斯积分规则：

| 名称 | 点数 | 多项式精度 | 用途 |
|------|------|-----------|------|
| `GAUSS_3PT` | 3 | 2 | 简单测试 |
| `GAUSS_7PT` | 7 | 5 | 旧版，已不推荐 |
| **`GAUSS_12PT`** | **12** | **6** | **自作用/相邻项默认** |

12 点高斯积分提供 degree 6 精度，能较好地积分弱奇异被积函数和光滑格林函数。

**双重积分**：

$$\iint_{T \times T} f(\mathbf{r}, \mathbf{r}') dS' dS \approx A_T^2 \sum_{i=1}^{N_g} \sum_{j=1}^{N_g} w_i w_j f(\mathbf{r}_i, \mathbf{r}_j)$$

## 10. 代码实现逻辑

### 10.1 标量势边界积分：`ANALYTIC_SCALAR_POT_1_OVER_R`

**输入**：场点 $\mathbf{r}$，三角顶点 $\mathbf{v}_1,\mathbf{v}_2,\mathbf{v}_3$

**输出**：$I_0(\mathbf{r}) = \int_T 1/|\mathbf{r}-\mathbf{r}'| dS'$

**算法**：

```
1. 计算单位法向量 n̂ = (v₂-v₁)×(v₃-v₁) / |...|
2. 计算场点到平面的有符号距离 H_PT = (r - v₁)·n̂
3. RESULT = 0.0
4. FOR 每条边 (V_START → V_END, 对顶点 V_OPP):
   a. t̂ = (V_END - V_START) / |V_END - V_START|
   b. m̂ = n̂ × t̂，若 m̂·(V_OPP - V_START) < 0 则翻转 m̂
   c. H_I = (r - V_START)·m̂
      S_START = (r - V_START)·t̂
      S_END   = (r - V_END)·t̂
      R_START = |r - V_START|, R_END = |r - V_END|
   d. 分类计算 CONTRIB:
      - 若 |H_I| < 1E-12: CONTRIB = 0 （场点在边的延长线上）
      - 若 R+S 均 > 1E-12: CONTRIB = H_I·ln((R_END+S_END)/(R_START+S_START))
      - 若靠近起点: CONTRIB = H_I·[ln(R_END+S_END) + ln(R_START-S_START) - ln(h²+H_I²)]
      - 若靠近终点: CONTRIB = H_I·[ln(h²+H_I²) - ln(R_END-S_END) - ln(R_START+S_START)]
   e. RESULT += CONTRIB
5. 计算立体角 Ω:
   r₁=v₁-r, r₂=v₂-r, r₃=v₃-r
   Ω = 2·atan2(|r₁·(r₂×r₃)|, r₁r₂r₃ + r₁(r₂·r₃) + r₂(r₃·r₁) + r₃(r₁·r₂))
6. 最终结果: I₀ = -RESULT - |H_PT|·Ω
```

### 10.2 线性势 / 矢量势：`ANALYTIC_LINEAR_POT_1_OVER_R`

**输入**：同标量势

**输出**：`RESULT_3(3)` = 三个线性势系数 $c_1, c_2, c_3$

**算法**：

```
1. 调用 ANALYTIC_SCALAR_POT_1_OVER_R 得到 I0
2. 计算 H = (R_PT - V1)·n̂, P_PROJ = R_PT - H*n̂
3. I_SHIFTED = 0
4. FOR 每条边:
   a. 计算 t̂ 和 m̂_out = -m̂_in
   b. S_START = (P_PROJ - V_START)·t̂
      S_END   = (P_PROJ - V_END)·t̂
      R_START = |R_PT - V_START|
      R_END   = |R_PT - V_END|
      D_I     = (P_PROJ - V_START)·m̂_out
      RHO2    = H^2 + D_I^2
   c. 稳定计算 LOG_TERM
   d. TERM = RHO2*LOG_TERM + S_START*R_START - S_END*R_END
   e. I_SHIFTED += 0.5 * m̂_out * TERM
5. I_VEC = P_PROJ * I0 + I_SHIFTED
6. 解线性系统:
   RESULT_3(1) = [(I_VEC - V3*I0) × (V2 - V3)]·n̂ / (2A)
   RESULT_3(2) = [(V1 - V3) × (I_VEC - V3*I0)]·n̂ / (2A)
   RESULT_3(3) = I0 - RESULT_3(1) - RESULT_3(2)
```

### 10.3 自作用项：`CALC_EFIE_SELF_TRI_PAIR`

**调用方式**：

```fortran
CALL CALC_EFIE_SELF_TRI_PAIR(MESH, TRI_ID, RWG_M, RWG_N, K, ETA0, Z_PAIR)
```

**流程**：

```
1. 提取 RWG_M 在 TRI_ID 上的系数 C_M 和对顶点 r_opp^M
2. 提取 RWG_N 在 TRI_ID 上的系数 C_N 和对顶点 r_opp^N
3. 用 12 点高斯做外层积分，得到 J0, J_RI0, J_VEC, J_RDOT
4. 计算 P_sing, Q_sing
5. 用 CALC_GREEN_SMOOTH_INTEGALS 计算 G_smooth 四积分
6. 计算 P_smooth, Q_smooth
7. Z_PAIR = C_M*C_N * [jkη0*(P_sing+P_smooth) + jη0/k*(Q_sing+Q_smooth)]
```

### 10.4 EFIE 矩阵元素入口：`CALC_EFIE_MATRIX_ELEMENT`

```
FOR I = 1,2  (RWG_M 的正/负三角形)
  FOR J = 1,2  (RWG_N 的正/负三角形)
    IF TRI_M(I) == TRI_N(J) THEN
       CALL CALC_EFIE_SELF_TRI_PAIR(...)
       Z_MN += Z_PAIR
    ELSE IF ARE_TRIANGLES_ADJACENT(TRI_M(I), TRI_N(J)) THEN
       CALL INIT_GAUSS_TRI(GAUSS_12PT, GDATA12)
       CALL CALC_GREEN_INTEGALS(..., GDATA12, ...)
       计算 P, Q
       Z_MN += C_M(I)*C_N(J)*(jkη0*P + jη0/k*Q)
    ELSE
       CALL CALC_GREEN_INTEGALS(..., GDATA, ...)
       计算 P, Q
       Z_MN += C_M(I)*C_N(J)*(jkη0*P + jη0/k*Q)
    END IF
  END DO
END DO
```

### 10.5 四个格林积分函数

`CALC_GREEN_INTEGALS` 和 `CALC_GREEN_SMOOTH_INTEGALS` 结构相同，区别仅在于使用的格林函数。返回：

| 符号 | 含义 |
|------|------|
| `I1` | $\iint G\, dS' dS$ |
| `I2` | $\iint \mathbf{r}_{\text{obs}} G\, dS' dS$ |
| `I3` | $\iint \mathbf{r}_{\text{src}} G\, dS' dS$ |
| `I4` | $\iint (\mathbf{r}_{\text{src}} \cdot \mathbf{r}_{\text{obs}}) G\, dS' dS$ |
